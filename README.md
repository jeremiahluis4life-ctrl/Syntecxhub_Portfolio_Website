# Syntecxhub Portfolio Website

Project 1 of the Syntecxhub Front-End Development internship: a single-page portfolio built with **HTML and CSS only**.

## What's in it

- **About:** intro, short bio and quick facts
- **Skills:** grouped by job, with real tech icons
- **Projects:** four live client sites (NURIGHT, Overite, URock Media, Advantage Care Group) with screenshots
- **Contact:** email, GitHub and LinkedIn

## Details

- Layout uses grid and flexbox and works from 320px phones up to wide desktops
- Hover effects: cards lift, buttons spring, screenshots zoom
- Smooth scrolling between sections, plus a one-time entrance animation
- Respects `prefers-reduced-motion`, has visible keyboard focus and a skip link
- No JavaScript and no frameworks

## Run it

Open `index.html` in a browser.
